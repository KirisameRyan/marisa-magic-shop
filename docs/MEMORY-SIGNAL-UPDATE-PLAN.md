## 固定工具栏与分模式教程

桌面采用左侧图标工具栏与单个右侧参数面板；手机采用底部图标栏与单个底部抽屉。图标保留简短文字与可访问名称，关闭面板后画布成为主体。8-bit 原有按钮全部收纳到风格、调节、动画、导出中，高级设置折叠。

开始默认触发当前模式教程，照片和动图各 5 步，静态像素图 4 步。完成状态按模式保存在本地，可随时重开、跳过或记住跳过。动画教程解释参考帧调参、渲染全帧以及 PNG/GIF 区别。全帧待更新提示收在动画工具，避免手机画面被横幅挤占。

新增验证脚本：node scripts/test-zyms-tools.mjs。效果截图和结果位于 artifacts/zyms-tools-review。
