# 页面创作与信息架构规范

## 分类与目录

`js/catalog.js` 中的 `MMS_LIBRARY.items` 是唯一作品目录。每个作品只有一个主分类；“精选”“新作”是展示属性，不再作为重复分类。

| 分类 | 放什么 | 主题标签 |
| --- | --- | --- |
| 游戏室 `games.html` | 有操作、胜负、成长或模拟流程的互动作品 | 动作街机 / 策略经营 / 剧情实验 |
| 测试屋 `tests.html` | 通过选择或问答生成结果的娱乐内容 | 性格身份 / 幻想二次元 / 生活趣味 |
| 故事角 `stories.html` | 阅读为主的虚构叙事、故事合集 | 虚构故事 |
| 工具与创作 `tools.html` | 导出作品、处理素材、记录数据 | 影像创作 / 日常工具 |

首页只放四个入口、一件主要新作和少量精选。分类页每页 9 件，使用 `q`、`tag`、`page` 查询参数；全站目录 `explore.html` 增加 `category`。刷新、分享链接和浏览器前进后退必须保留筛选条件。别再往首页塞所有作品。

新增条目字段：`href`、`name`、`category`、`tag`、`desc`，可选 `featured`、`badge`、`cover`。描述写具体玩法与限制；不要写“AI 精准”“科学鉴定”等无法证实的效果。多个版本应明确区分名称。

## 美术与资源

- 主站：纸色 `#F5F0E5`、墨绿 `#435744`、印章橙 `#AC592F`，细边线，小圆角，宋体标题与系统无衬线正文。
- 子页共享外壳：深森林底色，统一四分类导航、返回父分类入口、反馈链接。游戏可以保留各自的像素或街机视觉；创作工具以画布为主。
- 不使用紫色渐变、Emoji 导航、满屏粒子、成片发光卡片或循环悬浮动画作为默认装饰。Font Awesome 图标必须配可读文字或无障碍名称。
- 优先复用已有角色立绘与像素素材。首页使用现有 `images/logo.png`；记忆信号封面使用仓库原生 SVG，便于维护与缩放。资源归属、作者或授权信息有记录时应保留，无法确认的作品不要擅自标为原创。
- 新资源放 `images/<作品名>/` 或 `images/site/`，写清用途和来源；避免 UUID 文件名、重复拷贝、巨大 PNG 做小图标。
- 如果后续补充 AI 背景图：建议“魔法之森边缘的小杂货铺，黄昏暖光，纸本插画质感，墨绿与米白，无人物、无文字、无界面、左侧留出标题空间，16:9”。这属于可选视觉扩展，本版无需生成。

## 子页面结构

从 `templates/subpage.html` 复制到根目录开始，接入 `css/common.css`、`js/page-base.js`、`nav.js`。新作品逐步使用清晰目录名；已有 URL 保持兼容，迁移必须做重定向。

1. 页面头部：清楚的作品名、用途、返回所属分类入口。
2. 默认状态：给出可操作的示例或开始按钮；工具应允许不上传文件先体验。
3. 主工作区：保留足够空间；提示放在画布外侧；不要被悬浮导航遮挡。
4. 指南：说明玩法、鼠标/键盘/触摸操作，支持关闭并重新打开；不要只靠 Hover。
5. 状态与错误：空数据、加载中、失败、未登录、未配置 AI、导出限制都要有明确说明。不得向用户返回密钥、供应商错误正文或服务器路径。
6. 保存与离开：说明本地保存、云端保存和下载的区别。外部账号功能必须在服务端完成认证。

## 验收门槛

- 320、390、768、1024、1440 宽度无横向溢出；至少检查一次手机触摸交互。
- 支持键盘焦点、Escape 关闭菜单/指南、表单 Label、图片 Alt、`prefers-reduced-motion`。
- 检查所有本地链接、图片、脚本和导出；不能只检查页面返回 200。
- 新增目录执行 `node scripts/check-catalog.mjs`；更改发布规则执行 `python scripts/test-publication.py`；提交前扫描凭证。
- 禁止在前端硬编码任何供应商 Key、Bot Secret、SMTP 密码；禁止提交 `.env`、数据库、APK、ZIP、签名材料。公开目录只存允许发布的资源。
