# 注册逻辑审查与账户绑定

2026-11-01。本次审查覆盖本地网站注册、登录、重置密码及新增交易接口，未访问生产数据库、未发送真实邮件，也未部署到网站服务器。

## 已实现的规则

邮箱可留空；省略邮箱或提交空字符串都保存为 SQL `NULL`，多个无邮箱账户可以并存。填写时仍校验邮箱格式并禁止重复。注册弹窗与游戏帮助均明确说明：无邮箱且忘记密码，无法通过本站找回账户和关联游戏资产。邮箱验证不作为登录、开通游戏或参与排行的前置条件。

游戏账户使用现有网站 `users.id` 一对一关联。验证网站现有 Bearer 会话后，服务器创建游戏账户并只发放一次初始资金，不需要玩家另设游戏密码。网站退出、会话到期或重置密码后，旧会话不能继续交易。

## 修复记录

| 发现的问题 | 修改与验证 |
| --- | --- |
| 邮箱必填及唯一约束与新规则冲突 | 将旧 `email NOT NULL UNIQUE` 迁移为可空，保留用户 ID、自增序列、邮箱、会话、自定义列及索引；真实旧结构迁移测试通过。 |
| 注册缺少请求限制，并发重复检查和插入不在同一事务 | 增加每 IP 每小时 10 次注册尝试限额，使用 `BEGIN IMMEDIATE` 将重复检查、创建用户和签发会话包在事务内。数据库唯一约束保留。 |
| 登录、找回密码的 JSON 限流计数可能并发丢失 | 改用现有 `mms_quota` 文件锁原子计数；登录分别限制 IP 和用户名，找回分别限制 IP 和邮箱。 |
| bcrypt 对超长字节密码存在截断语义 | 新注册与重置密码统一为 8–32 字符、最多 72 个 UTF-8 字节，拒绝 NUL；旧账户仍可使用原密码登录。参见 PHP 官方 [password_hash 文档](https://www.php.net/manual/en/function.password-hash.php)。 |
| 重置密码链接使用后，其他重置链接和旧会话仍可能有效 | 单事务内消耗该用户所有重置链接、更新密码并撤销所有登录会话。测试确认第二条链接失效、旧会话全部撤销、新密码可登录。 |
| 重置页面的统计脚本可能读取带令牌的完整 URL | 移除该页统计脚本，加入 no-referrer，先从地址栏移除令牌再加载其余脚本；链接域名改由服务端可信配置决定。符合 [OWASP 找回密码建议](https://cheatsheetseries.owasp.org/cheatsheets/Forgot_Password_Cheat_Sheet.html) 中的链接和令牌保护原则。 |
| 网络故障被当成会话失效，提交按钮可能无法恢复 | 只在明确 401 时清除会话；网络错误返回可展示提示。游戏的重复下单使用幂等键避免扣款两次。 |
| 客户端伪造游戏资产、越权撤单或重复领取本金 | 交易服务直接核验网站会话，拒绝余额/用户 ID 等额外字段；所有正式结果来自服务器账本。两账户、幂等、越权、会话撤销测试通过。 |

## 验证与未覆盖项

本次通过 26 项原游戏核心断言、2 项注册集成测试、6 项多人服务测试及现有 PHP 后端检查。PHP 文件语法检查、目录清单检查、6 项发布边界测试及凭据扫描通过。浏览器在隔离的本机账户库验证了邮箱提示、网站登录与游戏绑定；实际生产 SMTP 投递、Nginx/systemd 配置以及真实旧库迁移仍需部署环境验证。

这不是完整渗透测试。无邮箱账户的密码恢复能力按产品决定关闭；注册限流不能保证一人一号。当前接口限流和同账户自成交防护不能阻止多个账户合谋，首轮公开测试不宜配置现实奖励。大规模并发、反操纵和 Toy 可信身份接入见 [服务说明](../services/exchange/README.md)。
