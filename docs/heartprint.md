# 二次元心动说明书（本地试玩版）

入口：`quiz-heartprint.html`。网站目录的测试屋已添加入口；本次未部署到线上。

## 数据与分类

- 当前题池 998 人：女 612、男 386。我的英雄学院角色已从题池和站内 v2 女/男/全库中剔除，不做补位。
- `node scripts/build-heartprint-data.cjs` 从现有全库生成新的计分视图 `data/heartprint-db.js`。
- 外观子类：发色、发长、发型、瞳色、外表类型、体型、肤色、服装、装饰/特殊特征。
- 综合子类：性格、沟通方式、价值观、身份/定位、种族/形态。
- 身份包括学生、战斗职业、魔法使、贵族、领袖、旅人、刺客、侦探、偶像、职场人、反派、导师、运动员、学生干部、治疗者、猎人、女仆、主妇、厨师、医生、对手等。
- 种族包括猫娘/兽耳、尾巴/兽人、角/鬼龙、翅膀/天使恶魔、精灵、吸血鬼/尖牙、机械/义体、人外/非人、神明/超自然。
- 种族标记同时会出现在视觉装饰和身份/种族里；结合角色时，同一条目会分别进入外观和身份线索。
- 作品基调、关系假设、年龄气质、年龄悖论、表情不参加这个版本的核心计分。
- 性格/沟通/价值观仍使用现有核心集，不是全部 v2 标签。鲁路修、L 这类角色的部分高频标签尚未映射，结果会偏窄；这是本版的已知限制。
- “绿发／灰发”“红发／粉发”等复合颜色不猜测拆分；对应颜色组暂不参与比较。
- 旧库没有逐图核验，新视图也不等于完成原作事实核验。详情见 `data/heartprint-migration-report.json`。
- 同义／相关来源合成一个计分 ID，例如 personality/loyal 与 values/val_loyalty。
- 不做 API 调用，不消耗模型额度。新数据来源是已经存在的本地库。

## 选择与统计

50 次有效选择，跳过不占次数。每轮替换双方，优先未见过的角色；50 轮范围内各题池足以避免角色重复。

- 默认结合角色：角色默认视为“了解”，复选框默认勾选；取消任意一方后，这一轮自动回退“只看外观”。
- 只看外观：只计 visual 标签，必须两张图片都加载完成。
- 结合角色：同时计 visual 和 character 标签，双方必须了解；不声称分离了外貌、剧情和情怀的影响。
- 共有标签既不计分也不算曝光；双方的标签组都具备可用信息才进行比较。
- 缺少整个分类不当成“没有该特征”；已标注分类仍可能不完整，这是数据局限。
- 偏好分 `100 × (wins-losses)/(n+4)`，按整数显示；不是概率。
- 至少 5 次差异比较且至少 3 个携带该特征的不同角色，进入可参考结果；不是显著性检验。
- 零曝光显示未测到，其他低覆盖显示线索不足，不进入主要画像。
- 12 轮以后约 35% 的抽题尝试补充已有正向但证据不足的稀有线索；只做出题曝光，不改结果分数。其余探索。
- 抽样和对手都会影响分数，不能解释成单一特征的因果作用。
- 结果按子类分组展示；外观组包含只看外观与结合角色的证据，综合组只来自结合角色；身份和种族是身份线索，不等于性格结论。

## 本地进度与导出

浏览器 localStorage：`mms_heartprint_v1`。续答保存当前题、熟悉度与历史；支持撤回、提前查看和继续。
记录只保存在本地；站点统计只上报开始/完成与总次数，不上报具体角色或标签。
导出 JSON 包含个人选择历史；海报只展示有足够证据的正向特征。
