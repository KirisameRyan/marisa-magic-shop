# 整手交易、盘口深度与临时停牌

2026-11-02。本地实现，需同步代码并重启交易服务后生效，不重置账本。

- 新委托每手 100 份，页面直接显示和输入份数，按钮每次加减100份，接口严格校验 100 的整数倍。单笔上限 100000 份，实际仍受资金、保证金和仓位限制；101 份、102 份的新买单会被拒绝。
- 五档基础深度从每档 100–500 份提高到 1000–5000 份，单侧基础总深度 15000 份。实际可见数量按库存及现金削减，并向下取整至整手，不承诺无条件成交。系统主动单每次 1000–4900 份，库存限制扩大至正负 20000 份，仍按现金和库存约束执行；资金不够买整手时改为考虑卖出，避免零股资金余量让系统卡住。
- 新委托的正常成交以整手进行。升级前已接受的委托继续保留；旧版零股持仓可整笔退出，NPC可承接其不足一手的尾数，不强行抹除或增加玩家份额。部分旧仓因此仍可能显示“手＋份”。旧仓的退出资金以实际成交与流水为准。
- 每只标的独立检查五分钟价格偏离，达到上下 10% 后，先记录触发的真实成交，再暂停该标的撮合 3 分钟。本批后续订单及暂停期间不继续成交；K线记录零量平价条，不生成假成交。保留余单和冻结资金，拒绝新委托，允许撤销普通余单及追加保证金。强平委托同样等待恢复，标记价暂停更新，恢复时可能有滑点和跳价。
- 到期后下一次分钟撮合恢复，以最后成交价重新设置临时参考锚点，避免旧参考价让同一段涨跌反复触发。之后继续滚动检查。ETF暂停成交时，其篮子 IOPV 仍按成分股更新。
- 不设全天涨跌停，不以当日开盘价或前收盘价限制价格；单日下跌 50% 或更多在规则上允许。原有相对最新价正负 20% 的单笔委托报价保护仍保留，它不限制整日累计涨跌。此停牌机制是本游戏自定义规则，不宣称复刻美股交易制度。

已验证：101份拒单、万份委托得到实质成交及整手分笔、旧123份持仓完整退出、停牌期间拒单及撤单、暂停条零成交、到期恢复、跌至前参考价40%仍可接受新委托。现有账户、撮合、保证金、ETF和PHP网关回归通过。

这次扩大流动性会改变滑点与价格冲击，暂停也会延后强平，建议更新前通知玩家并备份交易库。仍无无限接盘资金，不保证远离盘口的限价委托能成交。
