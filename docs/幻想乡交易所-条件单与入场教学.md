# 条件单、游客保存与交易所指南

## 交付范围

- 游客凭证与当前登录分开保存在浏览器。切换账户不删除游客凭证；有效期30天，访问验证时剩余不足7天会续期并轮换凭证。清理浏览器、跨设备或超过有效期仍可能无法恢复，不承诺永久匿名登录。
- 游客转正沿用原 user ID，更新用户名、密码与可选邮箱，撤销旧会话并移除游客标记。共享交易账户资金、持仓、条件单、教学记录不变。
- 系统正常双边报价的买一卖一差0.1，深层档位可空档，数量不再三角递增。报价中心随现价、库存、估值和玩家委托压力调整，主动订单混合价值、趋势与随机倾向；仍受真实模拟现金与库存上限约束。
- 新增条件单页面：止盈止损、MACD形态、反弹买入、回落卖出。每账户最多20条监控中订单，历史保留最多约80条。
- 右上角问号为可搜索说明书，涵盖交易、费用、保证金、技术指标、条件单、资讯、熔断、ETF、账户。首次进入自动五步教学，可跳过，服务端按账户保存版本1完成状态。

## 条件单规则

止盈止损按创建时持仓成本固定触发价格，支持价格与百分比；多空方向对称，比例指价格变化而非保证金收益率。同一组先触发的一方生成委托，另一方不再执行。创建时拒绝已经满足的止盈止损。卖出或普通平仓的保护数量不能超过未被其他保护或退出委托占用的数量。手动退出优先，随后按创建顺序缩减保护数量，清仓或反向则取消保护。监控不冻结买入资金，触发时按实际资金与仓位限制校验。

MACD固定12/26/9，支持1/5/15/30分钟、1/4小时、日线。按与图表一致的北京时间周期聚合，仅使用已完成K线，至少35根后启用。金叉与死叉比较DIF与DEA的前后关系；二次交叉默认30根窗口，中间必须出现反向交叉，可设3至100根。零轴过滤检查DIF、DEA同时零上或零下。顶底背离比较相邻两个严格确认高低点与对应DIF，左右各2根确认，转折点相距至多60根；第二点确认时才发信号。形态只监测创建后的新信号。

反弹买入跟踪最低成交价，回落卖出跟踪最高成交价，幅度可用百分比或价差。可选先跌/先涨的百分比激活条件，0为直接跟踪，参考价在创建时固定。每分钟只观察实际最新成交价，不推测分钟内路径。

触发在本批撮合与风险处理完成后判定，委托 submittedAt 为本批时间+1毫秒，最早下一分钟参与撮合。限价可不成交；对手价为带最大滑点限制的限价委托，不越过保护价格。失败显示原因，不无限重试，不回填过去的转折点成交。停牌期间继续保留条件，恢复后判断。触发后可以在“我的委托”撤销未成交数量，条件单本身不重复触发。

## 历史与性能

各标的各周期独立保存EMA状态、最近最多300根指标K线和形成中的聚合K线，不受图表36小时滚动窗口清理影响。缺少长期历史的4小时、日线指标必须等待积累，不生成虚构长期K线。相同标的、周期、形态参数的信号在单批内缓存复用。

本地合成检查：100账户、2000条日线MACD监控、20批完整市场tick加状态JSON序列化，平均34毫秒、最大66毫秒，状态约5.1MB。此检查不含HTTP并发、SQLite落盘、实际云服务器CPU与磁盘，不能视作线上容量保证。暂不加入固定5秒停单，当前单进程与数据库事务保证批次顺序，后续依据实际并发压测决定优化。整份状态写回仍是扩容时需要关注的瓶颈。

## 条件单行情与三类排行榜（2026-11-03）

条件单页与行情页共用一份现价、K线、MA、MACD和盘口。打开条件单时移动已有行情组件到编辑区旁边，不新建重复图表；返回行情恢复原位置。切换标的向服务器加载对应历史，并同步条件单标的。MACD周期选择同步图表周期，持仓与可用资金随行情更新。

排行榜分总资产、今日盈利、今日亏损。总资产按账户净值降序；今日盈亏=当前净值−本交易日开始净值，按北京时间04:00归档基准，包含浮动盈亏和费用。盈利榜仅收正值并降序，亏损榜仅收负值并升序（亏得多的在前）。每日收益率按本日初始净值计算，基准非正时不显示百分比。

仅开通且无历史成交、无有效委托、无持仓、无累计盈亏的空账户不入榜。提交有效挂单、持仓或实际交易过的账户保留总资产榜资格；曾交易但现在恰好持平的账户不因零盈亏被误删。每榜独立排名，保留展开主要挂单，接口分别缓存并校验榜单参数。不会清除任何账户数据。

验证覆盖过滤、排序、零值排除、04:00跨日归档、隐私和PHP网关榜单参数转发。更新后需重启交易后端。
