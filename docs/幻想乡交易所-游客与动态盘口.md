# 游客与动态盘口

游客入口调用网站 auth.php 的 guest 操作，服务器生成游客加六位数字名称，事务内检测现有用户名并由唯一约束兜底。游客占用真实用户 ID，共用服务器会话、交易账本与排行榜。已有有效会话再次调用不创建新账户。游客与注册共用每 IP 每小时十次的创建额度。游客没有可知密码或邮箱；凭证已独立保存在浏览器，切换账户后可恢复，临近过期会续期，也可升级为正式账户保留资产。清理浏览器或超过凭证有效期仍可能无法找回。详见《幻想乡交易所-条件单与入场教学》。

系统每分钟生成五档报价，同一分钟反复读取不会重新抽取深度。报价间距结合近十根 K 线振幅，中心考虑参考价值、现价、库存及现价附近的玩家买卖委托压力；各档数量结合时间、库存和波动调整，不再固定递增。系统主动委托每分钟一至三笔，方向综合参考价值偏离、近期收益、资讯压力和库存，规模与扫单档位变化。实际成交仍受现金、库存、整百份数量及熔断限制，不直接写入虚构价格或成交量，不保证玩家全部成交。

上线：更新前后端文件后重启 mms-exchange。账户迁移仅新增 guest_accounts 表，不覆盖现有账户或 K 线。
