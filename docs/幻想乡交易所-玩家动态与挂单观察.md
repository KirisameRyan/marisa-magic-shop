# 玩家动态与挂单观察

## 个股异常波动保护

现有规则按每只股票或ETF分别执行：五分钟参考区间涨跌达到10%，暂停撮合3分钟，允许撤单和追加保证金，拒绝新委托。到期后恢复，不设置全天涨跌停。这不是全市场指数熔断。此次增加停牌、恢复交易的资讯公告。

## 成交动态资讯

只记录升级后触发的交易动态，历史事件不追溯补写。

本批存在玩家参与成交，且单分钟涨跌达到3%、五分钟参考区间涨跌达到8%，或玩家参与成交量达到5000份之一时，生成“交易动态”。同一股票同类玩家成交报道冷却5分钟；停复牌公告单独记录。仅挂单、撤单不会被报道成成交或拉升。

报道记录股票、成交时间、实际价格变化、玩家参与的成交量及最多三位主要参与者的游戏昵称。双边均为玩家时，同一笔成交在市场统计中只计一次，各参与者的个人参与量分别统计。报道表示玩家参与及同期价格变化，不将全部涨跌归因于某个玩家，也不据此认定操纵。

这类报道不加入新闻价格影响队列，不重复改变参考价值，防止“玩家拉升→资讯利好→系统再次拉升”的自我放大。公司利好利空保持原有影响模型。“交易动态”可独立筛选，不混入基本面利好、利空筛选。

## 排行榜挂单观察

登录后可在排行榜展开玩家的主要挂单：显示当前有效委托笔数、剩余总份数、买卖方向汇总，以及按剩余数量排序的前五组委托。相同标的、产品、方向和限价的余单合并。显示标的、普通/合约方向、限价及剩余份数；部分成交与撤单后按实际余量更新。

不返回其他玩家的可用现金、持仓明细、保证金、杠杆倍数、会话令牌或可用于撤单的订单ID。原本公开的净资产及收益率继续展示。挂单意图不代表已成交，也可能撤回，不能把它当作确定的后续行情。

测试覆盖真实成交才发布、冷却去重、不进入价格影响队列、停复牌公告、合并余单、撤单及部分成交后更新，以及私有字段不进入排行榜响应。服务器更新后重启 `mms-exchange`，已有数据继续保留。
