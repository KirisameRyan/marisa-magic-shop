## 魔理沙幸存者（marisa_survivor.html + js/marisa-survivor.js）手机适配诊断（未改码，仅分析）

用户痛点：开始页简陋 / 暂停菜单冗杂 / 强制横屏后选角被挡 / 手机横屏显示不全+血条挡画面 / 希望 HUD 融入游戏场景。

诊断结论（浏览器实测截图存于 .workbuddy/tmp/01~09-*.png）：
- 根源：HUD（.hud/.bars/#bossBar/#pauseBtn）是 DOM 绝对定位锚在 .canvas-wrap 上，而 canvas 是 16:9 letterbox 居中，两套坐标系互不感知 → 血条横跨全屏悬在 canvas 外黑边、压在游戏画面顶部约 72px。
- canvas 固有 960×540 不放大（max-width/max-height 只缩不放），桌面 1440×900 下画面只占中间一小块。
- 横屏手机（844×390）overlay（选角页）flex 居中 + overflow-y:auto → 标题和"确认"按钮被裁掉看不见。
- 暂停面板 renderPauseStats() 把面板数值/武器矩阵/强化/遗物/超进化 5 大块全平铺滚动，"继续"按钮在滚动流里被数据挡住。
- 未开始时 HUD 裸露（满血条 + 000000 分数挂在开始页顶上，很出戏）。
- isTouch = 'ontouchstart' in window || maxTouchPoints>0 太宽，触屏笔记本会常驻摇杆。
- rotateOverlay 用 🔄 emoji，被 iOS 渲染成蓝色系统图标，与主题不符。
- body 用 100vh（iOS 地址栏坑），应换 100dvh。

改造方向（已与用户达成共识，待执行）：
1. HUD/血条/XP/Boss条/分数全部画进 canvas（ctx 绘制，与摇杆同思路），随 letterbox 自动缩放。
2. 开始页重做：立绘主角化 + 动效，公告收细，未开始时隐藏 HUD。
3. 暂停面板 Tab 化：顶部本局摘要 + 分区 Tab + 固定"继续"按钮。
4. 选角页横屏改横向布局 / clamp 字号，确认按钮 sticky。
5. canvas 按 wrap 尺寸计算放大（整数倍优先），100dvh，isTouch 用 pointer:coarse。

环境备忘：本地预览 python -m http.server 8642（后台任务）；agent-browser 需 --noproxy 直连 127.0.0.1。
