## 一、触屏按钮遮挡修复（上一轮方案照做）

main.js 新增 `setTouchUI(on)`，所有状态切换点调用：游戏进行中才显示摇杆+按钮层（z-15 的 joyArea 不再遮挡标题/暂停/结算等界面的按钮左半区）。

## 二、MIDI 音色软化 + 音量下调

- **master 链加低通滤波器**：BiquadFilter lowpass ≈2600Hz——方波/锯齿的刺耳高次谐波被削掉，整体听感圆润许多（这是“吵”的主因，比调音量有效）
- 主增益 0.24 → **0.20**，默认档位「中」0.6 → **0.5**（实际响度约降 35%）
- 音量按钮档位重映射：关 0 / 小 0.3 / 中 0.5 / 大 0.8，偏好持久化不变
- 复音上限 16 → 12（密集段落更清爽）
