# 旧核·梦核·怪核（Oldcore / Dreamcore / Weirdcore）图片滤镜 Web 应用 — 需求规格与对比测试文档

本文档为单文件 HTML「旧核·梦核·怪核图片滤镜」应用的标准化需求规格说明书（v3.0）。文档包含可直接复制投喂的测试提示词（Prompt）、核心功能与算法规格、三大美学预设矩阵、Seed 风格复刻机制以及模型横向评测打分表，适用于不同大模型或代码生成工具的对比测试。

## 一、 可直接复制的对比测试 Prompt

测试时可根据评测目标选择以下两个版本之一，直接复制发送给被测模型。

### 1. 完整基准测试版 Prompt（测工程实现上限、交互架构与像素级算法能力）

```text
请用纯 HTML + CSS + JavaScript 编写一个完整、可独立运行的单文件「旧核·梦核·怪核（Oldcore / Dreamcore / Weirdcore）图片滤镜」Web 应用，所有代码封装在单个 .html 文件中。

【核心需求与交互规范】
1. 界面布局与默认交互工作流（关键）：
   - 左侧为画布预览区与内置场景切换栏；操作提示文字必须放置在画布图片容器外部下方，严禁浮在图片上方遮挡画面。
   - 右侧控制面板默认展示「一键预设与预设总强度（0%~150%）」简易面板，并提供「打开高级细调模式」按钮。
   - 当用户在右侧选好一键预设并调节「预设总强度」后，点击「打开高级细调模式」时，所有细调滑块必须以当下实际生效的参数值为基准无缝承接，支持在此基础上继续微调；同时支持随时返回预设面板。
2. 风格 Seed 与参数复刻系统（Seed & Recipe Code）：
   - 点击「随机梦境（Randomize）」时，基于确定性伪随机数（PRNG）生成随机风格，并在界面显著位置展示当前专属 Seed（如 SEED-849201），用户下次输入该 Seed 即可 100% 复刻相同随机风格。
   - 当用户手动微调任意滑块、符号大小、旋转或镜像参数时，自动生成对应的紧凑型复刻码（如 DC1-...），支持一键复制与粘贴还原，方便用户保存或分享自己调校好的滤镜配方。
3. 图片加载与无图自举：
   - 支持点击上传、拖拽上传本地图片（JPG/PNG/WebP）。
   - 内置至少 4 张用 Canvas 2D API 程序化绘制的预设基底图（阈限走廊、千禧晴空、泳池空间、午夜游园），开箱即用，严禁引用外部网络图片 URL（防止跨域污染 Canvas 导致无法导出）。
4. 像素级滤镜渲染管线（必须基于 Canvas ImageData 与离屏图层混合实现，严禁仅用 CSS filter 敷衍）：
   - 光学与色彩：高光柔焦泛光（Bloom）、迷离双层重影（Ghosting）、曝光、对比度、饱和度、怀旧冷暖偏色、阈限品绿偏移、边缘晕影（支持深邃暗角与白雾梦境两种模式）。
   - 信号与退化：RGB 通道分离色差（Chromatic Shift）、低清像素降采样（CCD Pixelation）、恐怖色阶断层与深渊暗化（Abyss Crush / Posterize，用于重度怪核恐怖效果）、CRT 扫描线、磁带雪花噪点、VHS 水平撕裂抖动。
5. 梦核符号层（独立尺寸调节 + 旋转与镜像）：
   - 符号 1（复古 DV/相机日期戳）：支持开关、自定义文本、四角位置切换，以及独立的「日期戳大小调节（50%~220%）」。
   - 符号 2（VHS 磁带 OSD 状态码）：支持显示 `PLAY ▶ SLP` 状态字符，以及独立的「OSD 状态码大小调节（50%~220%）」。
   - 符号 3（怪核文字标签与眼部遮挡条）：支持白底黑字框、黑底红字警告条、纯黑眼部遮挡条、千禧黄发光字幕、Win98 报错框等样式，支持在画布上直接拖拽位置，并具备独立的「大小调节（50%~240%）」「旋转角度调节（-180°~+180°）」以及「水平镜像 / 垂直镜像」翻转功能。
   - 画幅边框装饰：支持无边框、CRT 显像管圆框、千禧拍立得相纸框，并支持边框粗细比例调节。
6. 三大流派共 12 款预设矩阵（旧核 / 梦核 / 怪核与重度恐怖）：
   - 【梦核 Dreamcore】：千禧午后、阈限走廊、深海残梦、游乐园残影。
   - 【旧核 Oldcore】：千禧数码机（2002 CCD）、90s 显像管电视、损坏磁带（VHS）、泛黄旧相册。
   - 【怪核与高能恐怖 Weirdcore & Horror】：怪核凝视，以及 3 款重度模拟恐怖模式——模拟恐怖档案（死寂黑红+高反差撕裂）、深渊精神污染（极限色阶断层+旋转镜像遮挡条）、午夜紧急广播（高压血色+系统崩溃弹窗）。
7. 对比与导出：支持「按住看原图」、一键重置、以及将包含全部像素滤镜与符号图层的结果导出为 PNG 图片。
```

### 2. 极简探索测试版 Prompt（测模型对「旧核/梦核/怪核」与架构设计的自主发挥能力）

```text
请写一个单文件 HTML 的「旧核·梦核·怪核图片滤镜」工具。要求：
1. 提示信息放在图片容器外面，不要遮挡画面；
2. 右侧默认展示三大分类预设（梦核、旧核、含重度恐怖模式的怪核）与预设总强度滑块，点击打开高级模式后以当前参数为准进行细调；
3. 支持随机生成并给出可复刻的 Seed 码，手动调好的模式也能生成复刻码一键还原；
4. 梦核符号层（DV日期戳、VHS状态码、怪核标签遮挡条）均支持大小调节，且怪核标签遮挡条支持画布拖拽、旋转角度与水平/垂直镜像；
5. 内置程序化默认测试图，所有滤镜基于 Canvas 像素级实现并支持导出 PNG。
```

## 二、 核心功能需求规格（Functional Requirements）

| 模块分类 | 功能项 | 具体需求说明 | 优先级 |
| :--- | :--- | :--- | :--- |
| **界面与工作流** | 画布无遮挡与外部提示栏 | 画布预览容器内保持纯净无遮挡，操作提示与当前状态统一放置于画布外侧下方的信息栏中。 | P0 |
| **界面与工作流** | 默认预设面板 + 高级模式承接 | 右侧默认显示「一键预设 + 预设总强度（0%~150%）」，点击「打开高级细调模式」后以当下计算出的实际参数值初始化全部细调滑块。 | P0 |
| **复刻与随机** | 随机种子（Random Seed） | 点击「随机梦境」生成确定性随机风格并输出专属 Seed（如 `SEED-849201`），再次输入该 Seed 可复刻完全一致的画面。 | P0 |
| **复刻与随机** | 自定义配方复刻码 | 用户手动微调任意滑块、旋转、镜像或文本后，实时编码生成紧凑复刻码（`DC1-...`），支持一键复制与粘贴还原。 | P0 |
| **像素级光学滤镜** | 柔焦泛光与双层重影 | 高光模糊叠加（Soft Bloom）与画面偏移双曝光重影（Dream Ghosting）。 | P0 |
| **像素级信号退化** | RGB 色差、像素化与 VHS 撕裂 | 操作 `ImageData` 实现红蓝通道水平色散、低清 CCD 降采样、CRT 扫描线、雪花噪点与水平行撕裂。 | P0 |
| **像素级恐怖劣化** | 深渊暗化与色阶断层 | 新增 `horrorCrush` 算法，压暗暗部至死黑、提亮中高频诡异血红并进行色阶量化（Posterize），支撑重度恐怖预设。 | P0 |
| **梦核符号层** | 三大符号独立尺寸调节 | DV 日期戳、VHS OSD 状态码、怪核文字标签/遮挡条（含画幅边框）均配备独立的 `50%~220%+` 尺寸缩放滑块。 | P0 |
| **梦核符号层** | 标签遮挡条旋转与镜像 | 怪核标签/黑条支持画布内拖拽定位、`-180°~+180°` 旋转角度调节，以及水平镜像（Flip X）与垂直镜像（Flip Y）翻转。 | P0 |
| **预设与导出** | 12 款三大流派预设 & PNG 导出 | 涵盖梦核（4款）、旧核（4款）、怪核与重度恐怖（4款），导出 PNG 包含完整像素滤镜与旋转/镜像后的符号层。 | P0 |

## 四、 模型对比测试评分表（Evaluation Rubric）

| 评测维度 | 权重 | 满分标准（优秀） | 常见扣分项 / 翻车点（差评） |
| :--- | :--- | :--- | :--- |
| **1. 默认预设工作流与高级模式承接** | 20 分 | 右侧默认展示分类预设与总强度滑块（0%~150%），切换到高级模式时各滑块数值与当前画面完全同步，提示文字位于画布外侧。 | 打开即堆砌几十个滑块无预设主次；预设强度与高级模式脱节；浮动提示遮挡图片。 |
| **2. Seed 与自定义配方复刻能力** | 15 分 | 随机时给出明确 Seed 且输入同一 Seed 可复刻；手动调参实时生成复刻码，复制粘贴后能还原全部滑块、文本与旋转镜像状态。 | 只有假随机按钮无 Seed 输出；或 Seed 只能复刻随机数、无法复刻用户自己微调的参数。 |
| **3. 梦核符号层尺寸、旋转与镜像** | 20 分 | 日期戳、OSD、怪核标签均支持独立缩放；怪核标签/遮挡条支持画布拖拽、`-180°~180°` 旋转及水平/垂直镜像翻转（Canvas 矩阵变换正确）。 | 符号大小固定不可调；旋转或镜像时文字坐标飞出画布或未围绕标签中心变换。 |
| **4. 旧核/梦核/重度怪核算法表现** | 30 分 | 覆盖旧核、梦核、怪核三大流派，重度怪核具备色阶断层/深渊暗化等强视觉冲击力算法，无外链跨域问题。 | 预设同质化严重，所谓“恐怖预设”只是单纯调暗亮度；或依赖外链图片触发 CORS 报错。 |
| **5. 导出完整性与交互性能** | 15 分 | 导出的 PNG 完整保留像素滤镜与旋转/镜像后的符号图层，滑块使用 `requestAnimationFrame` 节流，60fps 流畅。 | 仅用 CSS `filter` 导致导出原图；拖动滑块严重卡顿。 |
