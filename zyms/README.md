# 记忆信号 MEMORY SIGNAL

打开 `DREAMCORE __ 旧核·梦核·怪核图片滤镜实验室.html` 即可使用。CSS、渲染代码和四个程序绘制场景均内置于 HTML；Font Awesome 图标与 WOFF2 字体也已嵌入，单文件可离线使用。

## 使用

1. 初次打开显示引导页，可使用示例或导入 JPG、PNG、WebP。顶部“指南”可重看六步操作说明，页脚可重开初始页。
2. 选择梦核、旧核、怪核预设。缩略图基于当前图片实际渲染。
3. 用氛围、柔化、老化、异常调整参数组，或展开色彩、介质、光学、信号、局部遮罩进行细调。双击滑块恢复当前基准值。
4. 文字支持最多 12 个图层，包含透明度、旋转、镜像、排序、显隐；点击画面内的文字可选中并拖动。日期戳和播放状态独立设置。
5. 存为 A 后可继续调节并对比。撤销/重做支持 Ctrl+Z、Ctrl+Shift+Z。
6. 复制 DC2 配方用于精确复刻，保存配方写入当前浏览器本地存储。配方不包含图片。`SEED-数字` 还原新版随机风格；旧版 DC1 可迁移参数，但新版算法效果与旧版不完全相同。
7. PNG 导出保留图层，独立使用原图重新处理。支持原尺寸或最长边 2048 / 1024。原图处理上限 1600 万像素、最长边 8192px，超出会提示并等比缩小。

“效果混合”仅混合图片处理结果，文字和边框独立。变体区的“锁定色彩”只作用于生成四种变体；全局随机始终由 Seed 独立确定。

## 手机布局

760px 以下使用单列布局，工作台预览在滚动调参时固定在顶部，操作区分为风格、调节、图层。使用 Pointer Events 和指针捕获支持触摸拖动。欢迎页简化为单列，并保留所有入口。

## 开发

编辑 `studio-template.html`、`studio.css`、`studio.js`、`studio-guide.js` 和 `studio-scenes.js`，随后运行：

```powershell
python zyms/build.py
```

生成可独立携带的单文件 HTML。原始页面备份位于项目的 `artifacts/zyms-before-redesign.html`，构建不依赖该备份。

浏览器验证脚本：`node scripts/test-zyms.mjs`（需要本机 Chrome，输出保存在 `artifacts/zyms-review`）。验证包括配方像素一致性、确定性随机、场景和预设、历史、图层、引导流程、手机触摸、响应式布局，以及实际 PNG 下载尺寸。高清渲染使用主线程，大图导出期间界面可能短暂等待。
