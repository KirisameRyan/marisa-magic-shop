# 记忆信号 MEMORY SIGNAL

打开 `memory-signal.html` 即可使用。CSS、渲染代码和六个程序绘制场景均内置于 HTML；Font Awesome 图标与 WOFF2 字体也已嵌入，单文件可离线使用。

## 使用

1. 初次打开显示引导页，可使用示例或导入 JPG、PNG、WebP。顶部“教程”可重看当前模式的操作说明，顶部“首页”可重开初始页。
2. 选择梦核、旧核、怪核或胶片预设。缩略图基于当前图片实际渲染。
3. 用氛围、柔化、老化、异常调整参数组，或展开色彩、介质、光学、信号、局部遮罩进行细调。双击滑块恢复当前基准值。
4. 文字支持最多 12 个图层，包含透明度、旋转、镜像、排序、显隐；点击画面内的文字可选中并拖动。日期戳和播放状态独立设置。
5. 存为 A 后可继续调节并对比。撤销/重做支持 Ctrl+Z、Ctrl+Shift+Z。
6. 复制 DC2 配方用于精确复刻，保存配方写入当前浏览器本地存储。配方不包含图片。`SEED-数字` 还原新版随机风格；旧版 DC1 可迁移参数，但新版算法效果与旧版不完全相同。
7. PNG 导出保留图层，独立使用原图重新处理。支持原尺寸或最长边 2048 / 1024。原图处理上限 1600 万像素、最长边 8192px，超出会提示并等比缩小。

“效果混合”仅混合图片处理结果，文字和边框独立。变体区的“锁定色彩”只作用于生成四种变体；全局随机始终由 Seed 独立确定。

## 合并后的编辑器与来源

顶部只有「影像滤镜」和「像素与 GIF」两个主入口。原来的梦核/胶片与精修/图层已合为一个原生编辑器：同一底图、同一画布、同一配方与撤销历史。42 个预设中包含 9 个胶片预设；文字图层、日期、边框和局部遮罩直接在滤镜上编辑。换预设保留已添加的图层与遮罩。

上游照片滤镜管线与预设通过 `film_bundle.py` 从固定源码提取，接入现有 `studio.js`，不再嵌入独立的照片编辑页面。泛光和重影由现有编辑器处理，以保留阈值、半径和方向控制；高光红晕、柔雾、阴影抬升和污点等来自上游管线。装饰层由本地可编辑图层绘制，避免提前烘焙。旧版本地配方继续读取，上游数值型 DC2 可迁移到统一编辑器。

项目来源：[zhaoyuming3647-design / Retro-Style-Studio](https://github.com/zhaoyuming3647-design/Retro-Style-Studio)，固定提交 `5514b7dbbf5258cc3e8842cd26b724885455692b`。页脚与初始页保留来源署名。原始源码与依赖说明见 `vendor/README.md`。

像素/GIF 保留独立沙箱；正常来回切换不会覆盖照片项目。点击「将当前效果继续做像素」只传递合成副本，保留原照片的图层和滤镜状态。像素结果需要继续编辑时，明确带入当前帧作为新底图。

上游源码、预编译样式、GIF 解码器全部内置；无需 CDN，不上传图片。GIF 限 80 帧、单帧 4MP、总帧像素 24MP，文件限 40MB。

验证：`node scripts/test-zyms-retro.mjs`，覆盖实际合并、图层/遮罩/历史、上游配方迁移、模式往返不丢项目、真实 PNG/GIF 导出和响应式布局。

## 使用前说明与真实效果示例

初始页采用冰蓝、银白和糖果粉配色，与编辑界面保持一致。首次使用会显示完整的三步说明、梦核/胶片/像素的真实效果图，以及可拖动的处理前后对比。点击效果卡片可直接打开对应场景与预设；右上角「使用与示例」随时重看。新的首次使用标记独立于旧版标记，可选择下次直接进入。

所有处理方式共用顶部导入与导出。照片内部的滤镜、图层和局部效果直接一起编辑，无需转移底图。照片与像素之间仍可明确传递完整效果；GIF 带回照片编辑器时只使用当前帧。

效果图由内置场景和真实滤镜生成，不依赖外部图库或 AI 图片。运行 `node scripts/build-zyms-examples.mjs` 重新生成六张 WebP 后，再执行 Python 构建；图片会内置到单文件，不需额外发布。

## 固定工具栏与教程

桌面端左侧固定「素材、风格、调节、文字/动画、导出」五个带标签的图标工具；一次只展开一个右侧参数栏。手机端工具栏固定在底部，参数从底部抽屉展开，画布仍在上方可见。收起工具即可让画布铺满主体；参数在栏内滚动，页面本身不来回滚动。

照片的预设、局部遮罩与图层仍共用一张画布。8-bit 的主机和抖动收进各自工具，硬件规格、色板检查、对比缩放及序列帧导出继续保留在高级折叠项。动画工具集中播放、参考帧与全帧渲染；参数未应用到全帧时显示工具栏提醒点。

点击初始页开始或示例，首次默认进入当前模式教程。照片与 8-bit 动图各 5 步；静态像素图片自动省略动画章。顶部「教程」可重开；支持上一步、跳过及记住跳过选择。完整完成后按模式记住完成状态，之后直接进入。完成/跳过标记只存本地浏览器，不上传。

教程与工具栏验证：`node scripts/test-zyms-tools.mjs`。覆盖首次启动、两种教程、静态图跳过动画、固定面板开合、桌面侧栏/手机底栏、画布不被参数栏覆盖，以及零远程请求。

## 开发

编辑 `studio-template.html`、`studio.css`、`studio-skin.css`、`studio.js`、`studio-guide.js`、`studio-home.js`、`studio-tools.js`、`studio-tools.css`、`retro-tools.js`、`retro-tools.css`、`studio-retro.js` 和 `studio-scenes.js`，随后运行：

```powershell
python zyms/build.py
```

生成可独立携带的单文件 HTML。原始页面备份位于项目的 `artifacts/zyms-before-redesign.html`，构建不依赖该备份。

浏览器验证脚本：`node scripts/test-zyms.mjs`（需要本机 Chrome，输出保存在 `artifacts/zyms-review`）。验证包括配方像素一致性、确定性随机、场景和预设、历史、图层、引导流程、手机触摸、响应式布局，以及实际 PNG 下载尺寸。高清渲染使用主线程，大图导出期间界面可能短暂等待。
